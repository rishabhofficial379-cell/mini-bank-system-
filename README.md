#mini-bank-system
My First Python Banking System 🏦

Hey everyone! 👋

This is my first Python project that I uploaded to GitHub. I made a simple banking system using Python to practice what I have learned so far.

It's a basic program where you can log in using your name and PIN and do some simple banking operations.
What can it do?

    Check your account balance
    Deposit money
    Withdraw money
    Change your PIN
    Check for incorrect PIN attempts
    Lock access for 30 minutes after 3 wrong PIN attempts
    Exit the program whenever you want

What I used

    Python
    if-else statements
    while loops
    Dictionaries
    User input
    Basic input validation
    time module

How to run it

    Make sure Python is installed on your computer.
    Download or clone this repository.
    Open the project folder in your terminal.
    Run the Python file:

python main.py

(Change main.py to your actual file name if it's different.)
